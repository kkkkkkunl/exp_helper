# 工作簿与验收

## 六表契约

| 表 | 内容 | 数值关系 |
|---|---|---|
| 说明 | 参数、来源、内参、校准、0.5/1.0项目阈值、计数、最大差值和并列位置、完整异常与限制 | 质控汇总从明细公式链接 |
| 原始数据 | 完整逐孔原值及全部原始行JSON，来源和辅助参与状态分列 | 数值解析/有效状态公式，不覆盖原始列 |
| 复孔质控 | 分组、样本、assay、孔位、各Cq、均值、差值和等级 | 均值、差值与等级为公式，合格绿/异常橙红且有文本 |
| 计算过程 | 目标和实际内参各孔/均值、ΔCq、共同校准、ΔΔCq、表达量与来源QC | 每生物学单元一行，派生值公式 |
| 整理数据 | 无表头，仅分组、基因、相对表达量，分组优先再按目标顺序 | 值链接计算过程，显示3位而不截断精度 |
| 作图 | 各组实际n、均值、SD/SEM、风险提示、每目标原生柱图 | 公式汇总，缺失不画零，n<2不创建误差条 |

图无标题/图例、纵轴从0、轴名“基因名 relative expression”，零基线深灰实线、分组标签位于其下。同名多assay分开scope或在旁标识。默认QC风险值保留并提示，不加无依据统计标记。

## 四层验证

独立数学预期、XLSX公式/原生结构、真实引擎重算、每表每图实际渲染分别留证。XlsxWriter/openpyxl不作为重算引擎；缓存来自 Python 则如实说明。打开重算标志、数据模型生成成功、静态XML存在都不等于视觉通过。

有可用 Excel 时可执行交付的 `verify_excel.ps1`，只用独立隐藏实例打开指定合成/授权工作簿，保存重算、导出图与每表PDF并生成证据；验收执行前核对目标路径，旧用户工作簿不被连接。实际运行的工具/版本/覆盖记入manifest。缺工具时列未验证，正式发布不能称全部通过。

既定映射下的Cq与Excluded可重算；改变样本身份、纳入集合、分组或图表结构应重新运行分析并验收，不假装原生图对象能自行新增或迁移。无法计算数值空白，完整原因及身份留在明细。
