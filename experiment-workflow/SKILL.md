# 实验工作流：按需入口

先明确本次任务，不预读全部参考、脚本或分析技能正文。scripts 指本技能内路径，使用 Python 3.9 或以上，检查命令 JSON 的 ok。Windows 可用 py -3.9 -B。

## 定位与路由

- 已有项目用 project.py find 定位。仅安装、首次初始化或维护时读取 [安装说明](references/setup.md)，保留已有配置。
- 普通记录、补录只读 [记录模块](references/record-module.md)。数值回答保持会话草稿，明确保存才写入文件。
- 用户明确开始或继续实验，类型及模板或方案确定后，立即读 [实验技能与计算](references/experiment-skill-module.md)，按用户指定→模板绑定→实验类型定位目标 skill，只加载当前步骤相关内容。讨论备选不激活，不等待结果阶段或另发计算指令。
- 使用阶段模板、暂停、继续、继承样品或明确最终结果时读 [阶段交互模块](references/stage-record-module.md)；只有编写、校验或升级模板时再读 [模板规范](references/stage-template-rules.md)。
- 整理已有结果、结果分析或绘图时读 [结果模块](references/result-module.md)。上样计算由实验 skill 按当前步骤处理，不因启动而执行全部结果分析；原始数据附件本身不触发分析或实验结束。
- 每次明确保存记录后自动读 [库存模块](references/inventory-module.md)，核查本轮实际操作。直接库存指令也进入该模块，不按每个数值重复扣账。
- 安装返回日历待配置、阶段排期或事项更新时才读 [日历接入](references/calendar-integration.md)。首次询问服务和目标，连接对应插件／MCP，不固定某服务。
- 用户明确请求保存当前材料时读 [归档模块](references/archive-module.md)。最终结果整理完成自动检查归档，不要求另发归档指令。
- 只有用户要求 PPT 时才读 [汇报规则](references/report-rules.md)。

按相关范围校验：record、inventory、analysis（需技能名）、report、calendar；all 仅用于明确要求全面诊断。只记录不读取整个分析技能库。

## 共同约束

- 同实验暂停续接沿用编号；旧样品用于新实验另建实验编号，保留来源，不把前序操作复制为本次事实。
- 按模板集中提示步骤和待填信息，接受自由文本、多步骤输入，只问缺项及冲突。模板预设先展示确认，普通模板也适用，实测结果必须有实际来源。
- 普通回答不保存草稿、分配编号或写库存计划；阶段确认、暂停和明确最终结果分别授权对应保存动作。恢复依据已保存状态。
- 计算立即展示输入、单位、技能依据与结果，阶段确认或暂停保存时写入独立计算部分；实际量另据实际操作确认。计算不代表执行，不扣库存，不标结果完成。缺参或异常只暂停受影响部分。
- 首次保存固定所用技能内容依据，续接沿用，升级先展示差异及影响并确认。已存记录正文或属性修改前留存完整旧版到项目根 history，以实验编号和本次北京时间修改时刻命名；重试不重复，历史关联实验归档。
- “暂停”保存已执行部分并完成本次阶段收尾，未做步骤仍未执行并进入日历。排期缺日期、开始时间或时长时集中补问。
- 只有明确提交本次最终结果才自动整理及结束；整理完成后自动检查归档，受阻则保留授权，在后续调用补齐后继续。初步数据、普通讨论或单独附件不触发结束。
- completed、completed_at 只表示结果整理；纯过程为 false/null。important 默认 false，由用户标记整次实验重要性，与结果版本的精选独立。执行、复核及同步状态放内部。
- 记录、分析、结果整理、执行结束和归档独立；缺专业分析工具不虚构结果。日期等无关补录保留完成时间，相关变化只影响关联任务。
- 保留人工正文、标签及自定义属性；变更后重新展示合并再确认。保持真实操作、失败尝试与更正依据，不覆盖已提交库存历史。
- 不修复科研原图；附件冲突不自动覆盖或改名。数量、单位、授权与恢复细则只在相关模块加载。
- 日历按真实远端回执报告同步，不宣称离线后台服务；Git 始终由用户主动提交。

项目技能库沿用 skills/analysis，兼容实验级技能及独立分析技能，路径相对项目根。按名称只读目标，不扫描全库正文。缺失名称提示，重名拒绝覆盖，不自动下载。细胞 qPCR 模板 2.0.0 的计算由独立 cell-qpcr 承担，结果分析按请求交接 qpcr-ddcq；须先核对项目实际安装和工具。旧实验保留原快照，不以旧模板公式作为缺失技能的自动后备。

本仓库子技能源码统一放在 `sub_skill/`：qPCR 的安装源为 `sub_skill/cell-qpcr/` 与 `sub_skill/qpcr-ddcq/`，分别安装后仍按原名称及项目 `skills/analysis/` 索引解析；源码父目录本身不是技能入口。
