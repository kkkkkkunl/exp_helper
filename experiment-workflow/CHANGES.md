# v4：阶段模板、交互记录与日历续接

- 状态显式升级与模板内容固定，保留普通模板及旧 CLI。
- 按样品维护步骤、暂停收尾、真实重做和来源继承；未做内容不冒充已执行。
- 普通回答仅为草稿，预览确认后保存；记录、库存和日历分别保留可恢复状态。
- 阶段产物使用独立样品，库存更正留新事件及下游复核，不覆盖旧历史。
- 明确最终结果自动整理、结束并检查归档，支持文字证据与 important 属性。
- 首次安装选择日历并连接宿主插件／MCP，按阶段更新事项并保留手改时间。
- Windows/Python 3.9.10 合成验收及既有回归结果见源码项目 docs/v4-实施说明与验证.md；真实服务在首次接入时核查。

# v3：渐进加载与项目技能库

- 入口缩短为按需路由，记录、结果、库存、归档、安装拆成独立参考页。
- 校验按模块执行；只记录不读取技能索引或检查分析工具。
- 新增 install.py 与 skill_store.py，项目内相对路径安装、维护索引、按名称定位。
- 新增 organize 命令；结果整理、分析、归档独立。归档不以分析或整理完成为前提。
- 文档只自动维护 completed/completed_at；无关补录保留标记，相关变化局部失效。
- 每次记录完成返回 inventory_review；库存模块自动衔接，完整直接指令可作为该操作授权。
- 旧版库存事务、事件幂等和人工修改保护保留。迁移规则见 references/v2-operations.md。
