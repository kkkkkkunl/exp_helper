# 汇报版式规范

输出 `汇报.pptx`，可编辑。优先用 `python-pptx`；若项目配置了 `ppt_template`，在模板上填充。

## 页面结构

| 页 | 内容 | 约束 |
|---|---|---|
| 1 | 标题页：实验名称、实验编号、实际实验日期 | 编号必须与记录一致 |
| 2 | 目的 | 与记录「目的」一节一致，可压缩成 1–3 条 |
| 3 | 实验方法 | 只写实际操作；流程图可选；样本编号可标注 |
| 4+ | 结果 | 每个结果项一页或多页；图 + 简短说明 |
| 末 | 结论／后续计划 | **仅在用户提供文字时出现**；否则整页省略 |

## 版式

- 16:9，白底，无背景图案
- 字体：标题 28–32 pt，正文 18–20 pt，图注 12–14 pt
- 每页一个论点；图占主要面积，文字不超过 5 行
- 颜色：主色一种，强调色一种；不叠加渐变与阴影
- 图表直接插入原图，**不做美化、去噪、重绘**

## 禁止

- 自动生成结论、展望、"进一步研究"等填空句
- 自行新增统计检验、p 值、显著性标记
- 修复或重绘科研图片
- 在 PPT 里出现与记录不一致的数值

## 精选汇报

用户要求"精选"时，只选 `marked: true` 的结果版本：

```
python scripts/results.py filter --marked
```

未标记的版本不进精选页。

## 生成后自检

- [ ] 结论页每句话都能在用户原文中找到出处，否则删掉整页
- [ ] 所有图片未经处理
- [ ] 数值与记录一致
- [ ] 文件可被 PowerPoint / WPS 打开且可编辑
