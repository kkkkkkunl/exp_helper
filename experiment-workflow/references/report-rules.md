# 汇报规则

**R-57** 用户需要汇报时输出**可编辑**的 `.pptx`，保存为 `实验/<实验编号>/汇报.pptx`，并在实验记录中链接它。

**R-58** 结构固定为：目的 → 实验方法 → 结果 → 结论／后续计划。

**R-59** 结论与后续计划**只能使用用户亲自提供的文字**。用户没提供就整节省略，不要写"综上所述""后续将进一步探索"这类填空句。

**R-60** 不修复科研图片。原始图片按原样使用，不做去噪、增强、重绘。

**R-61** 统计分析由分析 skill 产出，PPT 只负责呈现。**不要自行新增统计分析**。

**R-62** 版式采用简洁科研汇报风格，见 `assets/report-layout.md`。

**R-63** 可基于已标记的结果生成精选汇报：只选 `marked: true` 的版本，未标记的不进精选。

**R-64** PPT 内容与记录保持一致：方法、结果数值来自记录，不得在 PPT 里另起一套数据。

## 生成方式

由宿主使用可用 PPT 工具生成；采用 python-pptx 时先核实依赖，不假定本机已经安装。用户提供 ppt_template 时在原模板上填充。本技能提供生成规则，不包含独立 PPT 渲染引擎。

生成后检查：

- [ ] 每页标题与结构一致
- [ ] 结论页的每一句都能在用户原文里找到出处，或整页省略
- [ ] 图片未经处理
- [ ] 结果数值与记录一致
- [ ] 文件能被 PowerPoint / WPS 打开且可编辑
