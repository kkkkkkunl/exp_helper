# 模板生成

使用本次会话中宿主提供的附件及用户明确指定的文件，先定位项目。用户指定方法及文件组合时只采用该组合，未选文件不得作为来源。方法和组合唯一时直接生成，多种组合时列出各候选方法及对应文件，等待用户选择。逐一读取所选文件，包括宿主支持的文档、表格和图像；无法读取时在对话中指出文件及原因，仅依据可读部分生成，全部不可读时停止。不得以扩展名推断方法。

从选定内容提取有依据的名称、适用范围、步骤、字段、表头及单位。方法文档依次包含方法名称与适用范围、来源文件、实验阶段与步骤、各步待记录项；来源只列实际使用的文件。根据 assets/experiment-record.template.md 构造空白记录，在对应章节保留表头、单位、顺序及待填字段，清除历史样本编号、数据行和实测值，不把来源不明的值当成默认值。缺少依据的位置留空，仅在对话中说明，不写缺项提示或推测内容。仅有结果表时保留表头，步骤留空。

存在同类方法时用 scripts/stage_templates.py 读出当前内容及版本，比较并逐项展示候选新增字段、单位和来源；等待用户选择沿用或选择要加入的字段。无新增字段或选择沿用时直接复用当前版本，不发布。更新时保持既有字段相对顺序，仅加入明确选中的新增字段，并构造完整的方法与空白记录。旧方法没有配套表时以通用布局为基础。足够的阶段定义须通过 scripts/stage_templates.py 的 parse_content 校验后采用 staged，其余使用 plain。

将 name、method、layout、format 和更新时所见的 expected_version 组成 JSON，通过标准输入调用 `scripts/template_publish.py --project 项目根 --input -`；无需将输入草稿落盘。脚本将两份内容和版本关联写入项目。若版本已变化，重新读取并展示实际差异，再等待选择。返回 reused 表示同一版本已存在。
