# Tasks

本清单覆盖整个项目。第 1 组是已完成基线，对应 design.md 的 B01—B15：已通过源码或交付文件定位，直接标记完成，不重复实施；基线勾选依据提案时的源码检查，实施后的重新验证单列于第 9 组。后续组为现有缺口、已确认新增需求及其验收。各能力规格首次进入 OpenSpec，不意味着基线代码需要重做。

**本次更新状态**：第 1—9 组的 57 项保留原有完成记录及验证范围；第 10—13 组是按实验启动与上样计算访谈 Q1—Q10 新增的 18 项，用户已明确调用 apply 授权实施，逐项勾选以本次证据为准。Q11 暂缓，本次不修改现有 qPCR 模板、不迁移其计算，也不交付具体 qPCR 专业技能。

**新增规划状态**：第 14 组依据 [`$exp` 入口与实验记录模板优化方案](../../../docs/exp入口与实验记录模板优化方案.md)增列，尚未实施或验证，均保持未勾选。前 75 项的完成状态不作为第 14 组的交付依据；本轮仍不修改现有 qPCR 方法模板或专业技能。

依赖顺序：状态兼容 → 模板与样品模型 → 阶段交互 → 结果归档及日历协调 → 安装说明 → 整体验收。并行分支也须保留当前事务和人工修改保护。

增量依赖顺序：技能激活与兼容模型 → 计算证据及授权保存 → history 与归档关联 → 集成验证及说明。实际验证见 [v5 实施报告](../../../docs/v5-实施说明与验证.md)。

新增规划依赖顺序：显式入口与共同定位 → 统一记录结构生成及校验 → 缺项问答和正文显示 → 旧记录迁移与综合验收。
