# exp_helper
帮助进行实验数据分析，实验记录的skill套装。自用

## 使用说明

### 一、安装与配置

安装主技能：提供github连接，告诉助手技能包和项目文件夹的位置，例如：“把这个 experiment-workflow 技能安装到我的××项目。”

安装实验技能：按需安装配套技能。例如，细胞 qPCR 使用 cell-qpcr和 qpcr-ddcq。

配置日历：按提示选择日历并完成授权；暂不连接也可以先记录实验。

### 二、日常使用

开始实验：说“在××项目中开始××实验”，提供方案和样品信息。

操作与记录：按提示填写实际操作；需要计算时提供参数，核对记录后说“确认保存”。

暂停与继续：说“暂停实验”保存当前进度；下次提供实验编号，说“继续实验”。

提交结果：说“这是本次实验的最终结果”，助手会整理结果并检查归档；需要分析或绘图时另行说明。

## 目前支持的功能

### 一、实验操作与记录

- **实验引导**：按方案提示步骤，记录样品、操作和实际用量。
- **实验计算**：根据配套技能计算用量，展示参数、单位和结果。
- **暂停续接**：保存当前进度，下次继续；使用旧样品开展新实验时保留来源。
- **记录追溯**：修改已保存记录时保留旧版本，方便核查。

### 二、结果与日常管理

- **结果整理与归档**：提交最终结果后整理记录，并自动检查归档。
- **数据分析与绘图**：通过配套分析技能处理数据，目前提供 qPCR 相关技能。
- **库存管理**：保存记录后核查实际耗材用量，计算本身不会扣减库存。
- **日历排期**：连接日历后安排后续实验，并同步相关事项。
