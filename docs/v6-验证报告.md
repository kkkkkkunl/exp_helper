# v6 实施说明与验证：`$exp` 入口及正式记录结构

## 实施范围

本轮对应 `complete-experiment-workflow-lifecycle` 变更第 14 组任务。已在仓库交付 `exp/SKILL.md` 薄入口；主技能仍以 `experiment-workflow` 名称可直接调用。入口只定位同级主技能，不把入口调用本身视为实验保存授权。个人技能目录的部署不属于本轮仓库修改。

新正式记录的结构由 `experiment-workflow/assets/experiment-record.template.md` 提供，`scripts/record_format.py` 负责渲染和结构校验。普通记录经阶段预览与保存、显式 `workflow.py record` 均复用该校验。模板说明、占位符、虚构数据不进入正式正文；空目的、结果和附件可保留。旧格式记录在普通编辑中沿用原排版，显式 `migrate-preview` 和 `migrate` 才转换；预览哈希绑定原文及候选，旧版由现有 history 事务保存。

阶段预览提供当前阻断项的结构化 `questions` 与编号文本 `fallback`。宿主优先使用问答框，候选来源于已给出的冲突值或会话北京时间，无法可靠推定的值使用开放输入。相对时间确认前不写入正文；确认后单项值只显示值与必要单位，原话、候选、读取时刻、估计性质及确认状态留在内部状态。
