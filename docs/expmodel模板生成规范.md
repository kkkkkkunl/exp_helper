# /expmodel 模板生成规范

## 入口与产物

用户输入 `/expmodel` 并提供来源文件，系统提取内容，生成可复用的方法模板及其配套空白记录模板。来源文件无需预先整理成指定表格。

## 固定格式

1. 方法模板依次包含方法名称与适用范围、来源文件、实验阶段与步骤、各步待记录项。
2. 空白记录沿用项目的基本信息和“目的、实验方案（参考方案、实验方法）、结果、附件”结构。
3. 同一种实验复用已确定的字段、表头及顺序，数据行数可随实际样本数变化。

## 同类模板更新

再次导入同类实验文件时复用已有模板。新出现的字段列为候选，由用户选择是否纳入。用户选择更新后，方法模板和空白记录模板配套生成新版本。

## 生成范围与依据

涉及多个实验或多份材料时，按用户选择的范围和组合生成。缺少依据的内容仅在对话中说明。生成文件保留规定的结构，相应位置留空，不写“待补”或推测内容。空白记录中的实际执行数据留给每次实验填写。

1. 指令已指定方法和来源文件时，直接使用所选范围。
2. 仅输入 `/expmodel` 并附材料时，若材料对应一种明确方法且组合唯一，直接生成。若有多种方法或组合，先列出候选方法与对应文件，按用户选择生成。

## 首次保存与复用

首次生成后，将方法模板、空白记录模板及其版本对应关系一并保存到当前实验项目，供后续实验选用。

### 新建实验与正式保存

1. 用户通过 `/exp` 新建实验并选定方法后，系统按方法版本自动调出配套空白表，在当前会话生成本次实验独立的填写稿。填写和修改只作用于本次实验。
2. 首次正式保存前沿用会话草稿规则。所选样式和填写内容仅保留在当前会话，结束会话后无草稿恢复要求。
3. 首次正式保存时固定本次所用方法版本与记录格式。发布新版后，重新打开已保存实验仍使用原格式。

## 验收示例

| 输入或情形 | 生成行为 | 可核对的结果 |
|---|---|---|
| 用户指定用附件 A、B 为一种方法建模，另附 C | 仅从 A、B 提取 | 方法模板列出的来源为 A、B；当前项目中可选用配套模板 |
| 材料对应两种方法，用户尚未选择 | 在对话中列出方法与对应文件 | 选择前不生成；选择后只保存所选组合 |
| 所选文件只有结果表 | 提取表头，保留空白记录结构，在对话中说明缺少步骤依据 | 模板保留表头，不含历史实测值和缺项提示 |
| 同类实验新增一个候选字段 | 在对话中展示差异 | 沿用时表头不变；选择更新时生成配套的新版本 |
