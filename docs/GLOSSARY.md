# 实验工作流

本术语表记录本次优化中已确认的业务概念；现有实验、样品等基础术语仍见 skill 内 references/glossary.md。

## Language

**一次记录**：对一次输入及其相关材料进行实验记录整理的工作单元。同一实验可以经历多次记录；一次记录完成不代表整个实验完成。
_Avoid_：把“一次记录完成”称为“实验结束”

**库存处理**：根据实际样品操作维护入库、取用、归还、分装、转移或报废等库存信息的工作。每次记录完成后自动触发，也可由独立的库存指令触发。
_Avoid_：把库存处理限定为结果分析的后续步骤

**归档**：保存当前实验记录与已有材料，使其能够被检索和追溯。归档不要求数据分析已经完成。
_Avoid_：用“已归档”表示“分析已完成”

**结果整理**：将本次要求整理的已有结果组织进实验记录的工作。该工作完成不意味着所有原始数据均已分析，也不等于实验成功。
_Avoid_：用“分析完成”代指结果整理完成

**数据分析**：根据实验数据和分析方法产生计算、统计或图表结果的工作。它可以晚于记录归档完成。

**项目技能库**：归属于一个项目、供该项目按名称选用的实验级技能与数据处理技能集合。
_Avoid_：用全机共享技能库代指项目技能库

**实验确定**：用户明确开始或继续某次实验，且实验类型及所用模板或方案已经明确的状态。
_Avoid_：把讨论备选实验视为实验确定

**实验级技能**：针对某类实验、统一提供准备、上样计算及结果处理规则的技能，可复用独立的数据分析技能。
_Avoid_：将实验级技能限定为结果分析技能

**计算上样量**：依据实验规则及输入信息计算得到的拟用样品量，不代表已经实际使用。
_Avoid_：将计算上样量称为实测用量或已使用量

**实际上样量**：用户报告或明确确认在实际操作中使用的样品量，可以与计算上样量不同。
_Avoid_：仅因完成计算就认定已经上样

**记录历史版本**：已保存实验记录在修改前保留的旧版内容，与当前有效记录区分，供更正与重算追溯。
_Avoid_：把未保存的会话草稿称为记录历史版本

**阶段续接**：同一次实验暂停后，从已保存进度继续记录和执行，沿用原实验编号。
_Avoid_：仅因跨天或重开会话就另建一次实验

**样品继承**：新的实验使用此前已有的样品，并关联其来源实验及来源阶段。新实验创建新编号，前序操作通过链接追溯。
_Avoid_：将来源实验的操作复制成当前实验已执行的操作

**交互式记录**：依据已选模板或用户提供的方案提示步骤与待填信息，由用户提供实际数据，会话集中整理并追问缺项或冲突。

**会话草稿**：尚未获明确保存授权的本轮整理内容，不写入项目文件；阶段确认、暂停或明确提交最终结果按已确认规则触发相应保存流程。

**实验阶段**：方法模板中的过程单元，包含具体步骤，并声明正常入口、暂停点和继续条件。阶段进度按具体样品分别维护。

**实验步骤**：阶段内的一项操作及其相关待填信息，是会话集中收集实际信息的基本单元。

**模板暂停点**：模板明确声明可以暂停的位置；会话停止或意外中断不自动等同于到达模板暂停点。

**阶段产物**：模板声明为新材料的样品，具有独立样品编号，并关联来源样品、产生实验及阶段；分装沿用既有分装语义。

**阶段确认**：用户对已展示的阶段事实及具体库存变更清单作出的保存授权。未展示或信息不完整的库存变更不在授权范围内。暂停时已执行部分作为本次阶段完成，未执行步骤转日历待办，各步骤仍保留真实状态。

**阶段尝试**：同一实验中一次真实执行某阶段的过程；失败重做产生新尝试，保留此前事实及实际消耗，不等同于技术重试。

**事实更正**：纠正已保存记载，保留前后信息与依据，并核对相关下游影响；不同于真实再做一次操作。

**实验重要标记**：记录属性 `important`，表示整次实验是否被用户标为重要，默认 false；与结果版本的精选标记独立。

**实验待办**：暂停后未执行的后续内容及待补事项，直接进入首次安装时选择并接入的日历；每个后续阶段一条事项，包含步骤、样品及记录位置，保留稳定标识以更新和防重复，不另建用户维护的待办.md。

## qPCR 数据整理

本节记录用户在 qPCR 技能设计中明确的领域语义；计算规则和可配置参数另见设计访谈，不在术语表中定义实现。

**技术复孔**：对同一生物学样本、同一基因的重复检测孔，用于获得该样本该基因的平均 Cq。
_Avoid_：把技术复孔数称为独立生物学样本数

**生物学重复**：实验设计中明确标识的独立生物学样本，不因存在多个检测孔而自动成立。
_Avoid_：仅凭孔位、重复行或名称后缀推定独立生物学重复

**内参基因**：与目标基因在对应样本中配套检测、用于计算 ΔCq 的基因。
_Avoid_：把内参基因与校准组混为一谈

**校准组**：作为同一目标基因表达变化参照的实验分组。
_Avoid_：将校准组的每个生物学重复解释为必须具有相同的相对表达量

**校准基准 ΔCq**：本技能中同一目标基因校准组的 ΔCq 参照值；存在独立生物学重复时，为各重复 ΔCq 的算术均值。
_Avoid_：用校准组相对表达量的算术均值替代 ΔCq 参照值

**严格复孔合格**：按用户指定规则，复孔有效 Cq 的最大差值小于 0.5 Cq 的状态。
_Avoid_：把差值等于 0.5 Cq 称为严格合格，或将此项目阈值称为通用行业标准

**有效检测孔**：具有可用于计算的数值 Cq、且未被仪器明确标记为 Excluded 的检测孔；有效状态不等于所在复孔组的严格质控合格。
_Avoid_：因复孔差值不合格就把所有数值孔自动排除

**未检出或缺失 Cq**：原始记录为 Undetermined、No Ct、空白或其他不能作为数值 Cq 使用的状态，保留其原始内容，不默认替换成零或固定循环数。
_Avoid_：把未检出解释为表达量为零

**固定内参分析范围**：一次进行相互比较的样本集合，其 ΔCq 使用同一选定内参，不因某样本缺失该内参而逐样本切换。
_Avoid_：将缺少同一样本的 GAPDH 解释为可以直接借用其他组 GAPDH 或切换 actin

以上定义来源：本次 qPCR 技能请求及第一、二轮用户回答；术语区分服务于本项目，不代表已验证特定实验的内参稳定性或方法适用性。

## 细胞 qPCR 模板

**RNA 当量浓度**：按逆转录所用起始 RNA 质量、反应体积及后续稀释倍数定义的模板当量，不是实测 cDNA 浓度。
_Avoid_：将 RNA 当量称为 NanoDrop 测得的 cDNA 浓度

**配液组成组**：单孔中各类组分体积相同、可使用同一份公共底液的一组反应。引物的具体身份可不同，但其加入体积须满足该组组成。
_Avoid_：把不同补水量或不同引物体积的反应合为同一公共底液

**配液块**：同一板、同一模板或阴性对照、同一配液组成组对应的一份样品预混液。与实验分组及生物学重复身份分别记录。
_Avoid_：把 NTC、−RT 与 RT 样品放入同一配液块

本节用于本轮细胞 qPCR 模板重建；用户已选择保留三级 mix，具体计算与字段见方法模板，不将配液参数作为术语定义。
