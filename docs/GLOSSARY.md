# 实验工作流

本术语表记录本次优化中已确认的业务概念；现有实验、样品等基础术语仍见 skill 内 references/glossary.md。

## Language

**一次记录**：对一次输入及其相关材料进行实验记录整理的工作单元。同一实验可以经历多次记录；一次记录完成不代表整个实验完成。
_Avoid_：把“一次记录完成”称为“实验结束”

**库存处理**：根据实际样品操作维护入库、取用、归还、分装、转移或报废等库存信息的工作。每次记录完成后自动触发，也可由独立的库存指令触发。
_Avoid_：把库存处理限定为结果分析的后续步骤

**归档**：保存当前实验记录与已有材料，使其能够被检索和追溯。归档不要求数据分析已经完成。
_Avoid_：用“已归档”表示“分析已完成”

**结果整理**：将本次要求整理的已有结果组织进实验记录的工作。该工作完成不意味着所有原始数据均已分析，也不等于实验成功。
_Avoid_：用“分析完成”代指结果整理完成

**数据分析**：根据实验数据和分析方法产生计算、统计或图表结果的工作。它可以晚于记录归档完成。

**项目技能库**：归属于一个项目、供该项目按名称选用的实验数据处理技能集合。
_Avoid_：用全机共享技能库代指项目技能库

**阶段续接**：同一次实验暂停后，从已保存进度继续记录和执行，沿用原实验编号。
_Avoid_：仅因跨天或重开会话就另建一次实验

**样品继承**：新的实验使用此前已有的样品，并关联其来源实验及来源阶段。新实验创建新编号，前序操作通过链接追溯。
_Avoid_：将来源实验的操作复制成当前实验已执行的操作

**交互式记录**：依据已选模板或用户提供的方案提示步骤与待填信息，由用户提供实际数据，会话集中整理并追问缺项或冲突。

**会话草稿**：尚未获明确保存授权的本轮整理内容，不写入项目文件；阶段确认、暂停或明确提交最终结果按已确认规则触发相应保存流程。

**实验阶段**：方法模板中的过程单元，包含具体步骤，并声明正常入口、暂停点和继续条件。阶段进度按具体样品分别维护。

**实验步骤**：阶段内的一项操作及其相关待填信息，是会话集中收集实际信息的基本单元。

**模板暂停点**：模板明确声明可以暂停的位置；会话停止或意外中断不自动等同于到达模板暂停点。

**阶段产物**：模板声明为新材料的样品，具有独立样品编号，并关联来源样品、产生实验及阶段；分装沿用既有分装语义。

**阶段确认**：用户对已展示的阶段事实及具体库存变更清单作出的保存授权。未展示或信息不完整的库存变更不在授权范围内。暂停时已执行部分作为本次阶段完成，未执行步骤转日历待办，各步骤仍保留真实状态。

**阶段尝试**：同一实验中一次真实执行某阶段的过程；失败重做产生新尝试，保留此前事实及实际消耗，不等同于技术重试。

**事实更正**：纠正已保存记载，保留前后信息与依据，并核对相关下游影响；不同于真实再做一次操作。

**实验重要标记**：记录属性 `important`，表示整次实验是否被用户标为重要，默认 false；与结果版本的精选标记独立。

**实验待办**：暂停后未执行的后续内容及待补事项，直接进入首次安装时选择并接入的日历；每个后续阶段一条事项，包含步骤、样品及记录位置，保留稳定标识以更新和防重复，不另建用户维护的待办.md。
