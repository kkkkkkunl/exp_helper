# 阶段重做、事实更正与模板兼容

状态：已实施；各轮修订边界保留如下，当前验证范围见 [v4 实施报告](../v4-实施说明与验证.md)。

## 决定

1. 同一实验的阶段真实重做新增一次尝试，保留原尝试的事实、结果与消耗，只重做失败样品。完整重复开展的新实验另建编号。
2. 允许使用缺少完整历史的旧样品或外部样品，已知信息如实记录，未知不补造。缺少必要库存信息时暂停相关提交；不满足模板继续条件时不自动指导继续，但允许保存进度。
3. 用户可选择模板允许的分支；超出模板的变更先展示并确认。实际偏离按事实记录，不自动改写为按模板执行。
4. 事实更正保留前后内容及依据，展示影响范围后确认；相关下游内容待复核，实际已发生操作不被更正成未执行。库存更正展示独立调整清单，不重复扣减。
5. 旧模板保留普通记录模式，不自动推断阶段；参数预设同样需要确认。新模板遵循阶段规范；每次实验固定启动时模板内容及版本，升级前展示映射和影响并获确认。

## 权衡与后果

- 区分真实重做、记载更正及新实验，保持操作与库存可追溯。
- 允许不完整历史接入，但未知信息不能替代继续操作或提交库存所必需的依据。
- 下游复核基于受影响关系，不抹去已发生事实，也不无差别重置其他任务。
- 旧模板可继续使用；新阶段模式与已有实验的迁移必须明确。
