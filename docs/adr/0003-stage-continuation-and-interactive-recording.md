# 阶段续接、样品继承与交互式记录

状态：已实施；各轮修订边界保留如下，当前验证范围见 [v4 实施报告](../v4-实施说明与验证.md)。

修订说明：关于暂停和“实验结果”触发的后续要求见 [ADR 0005](0005-pause-result-and-automatic-archive.md)；本页保留第一轮确认依据。

## 背景

用户要求后续实验模板支持阶段暂停、从中间阶段开始、复用此前实验的样品，以及由会话提示步骤、用户提供实际数值的记录方式。

## 决定

1. 同一实验暂停后继续沿用原实验编号。使用旧样品开展新的实验时创建新实验编号，关联样品、来源实验和来源阶段，不将此前操作写作本次操作。
2. 下一步操作及待填信息来自已选模板或用户提供的实验方案；缺项明确指出，不自行编造实验流程或实际参数。
3. 按步骤集中收集信息，允许自由文本和多步骤输入，只追问缺失或冲突信息，阶段结束展示汇总。
4. 普通回答先形成会话草稿。只有用户明确确认本阶段或要求暂停并保存，才写入记录及恢复状态；跨会话恢复以已保存状态为依据。Git 提交由用户主动执行。

## 权衡与后果

- 沿用编号便于同一实验跨会话继续；新实验通过来源关系追溯已有样品，避免重复书写前序操作。
- 模板限定提示依据，实际数据由用户提供；预设参数的确认方式已由 [ADR 0004](0004-stage-model-sample-lineage-and-confirmation.md)明确。
- 集中收集减少逐字段往返，同时需要识别自由文本中的缺项与冲突。
- 显式保存保留用户对文件写入的控制；未保存的会话草稿不构成可恢复的项目进度。
- 阶段结构、材料产物、多样品进度和库存授权已在 ADR 0004 确认，不能仅由本页第一轮决定推断。
