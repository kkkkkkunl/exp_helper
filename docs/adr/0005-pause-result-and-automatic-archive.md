# 暂停、实验结果与自动归档

状态：已实施；各轮修订边界保留如下，当前验证范围见 [v4 实施报告](../v4-实施说明与验证.md)。

## 背景

用户在 Q16 指定新的指令式流程，修订此前暂停不标阶段完成、实验记录需单独请求归档的建议。

## 用户明确的要求

1. 输入“暂停”后，当前阶段视为完成，后续实验内容转入待办。
2. 输入“实验结果”后自动整理，整理后视为实验结束；结果整理完成后自动归档。
3. 归档时可以标记是否重要。

## 已确认的边界

- 中途暂停只将已执行部分作为本次已完成阶段；步骤仍保留真实执行状态，未做步骤转待办，缺数据另列待补。
- 仅明确提交本次最终结果才触发结束流程，普通讨论、初步结果和单独上传附件不触发。当前提交的结果写入记录且附件关联完整后标为整理完成，必要缺项不能跳过。
- 归档前检查未通过时保留已达到的状态，归档等待补齐；后续沿用本次授权自动归档，未完成待办不自动完成。
- 待办直接写入日历，不另建实验待办.md；目标服务在首次安装时选择，排期与更新规则见 [ADR 0007](0007-calendar-onboarding-and-followup.md)。
- 记录属性新增实验级 `important`，默认 false，用户可指定或事后修改，不阻塞归档，与结果精选独立。

## 适用范围

本决定描述实验记录的暂停与归档，不等同于 OpenSpec 项目变更归档或 Git 提交。Git 仍由用户主动执行；会话中的普通参数回答仍不构成任意文件写入授权。

## 后续关联

日历服务选择、无日期排期及事项更新规则已在第四轮确认，见 ADR 0007。合并方案已按用户明确的 OpenSpec apply 请求实施。
