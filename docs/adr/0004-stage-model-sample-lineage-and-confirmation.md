# 阶段结构、样品来源与阶段确认

状态：已实施；各轮修订边界保留如下，当前验证范围见 [v4 实施报告](../v4-实施说明与验证.md)。

修订说明：第 5 项中“暂停保存不标为阶段完成”的边界已由用户在 Q16 修改，最新要求见 [ADR 0005](0005-pause-result-and-automatic-archive.md)：暂停将已执行部分作为本次已完成阶段，未执行步骤转日历待办，各步骤保留真实状态，未知数据不补造。本文第 5 项保留第二轮决定的历史依据，现行规则以该修订及[完整方案](../阶段式实验与交互记录设计方案.md)为准。

## 背景

[ADR 0003](0003-stage-continuation-and-interactive-recording.md)确定了实验身份、模板提示和显式保存边界。阶段结构与样品进度必须进一步明确，并与现有库存授权规则协调。

## 决定

1. 模板采用阶段包含步骤的结构，声明正常入口、暂停点和继续条件。会话可随时停止，实际意外中断如实记录，不自动认定可以直接继续。
2. 新材料产物建立独立样品编号，关联来源样品、产生实验和阶段；普通取用沿用原身份，分装遵循原规则。
3. 按具体样品分别保存阶段进度，允许集中处理相同步骤；部分样品继续不改变其他样品进度。
4. 模板预设参数只是参考。用户提供实际值或明确确认所展示的参数后，才能写入实际操作；实测结果不能由模板生成。
5. 信息不完整时仍可显式保存已确认事实与待补进度，但不得标记阶段完成。未知值不填零；未测定或不适用须用户明确选择并符合字段规则。
6. 阶段汇总列明记录和具体库存变更，用户的一次确认覆盖所展示的内容；未展示或不完整的库存变更不提交，独立进度仍可保存。

## 权衡与后果

- 区分会话暂停与实验操作中断，避免由记录状态推断操作条件。
- 独立产物和样品进度增加关系维护，但支持跨实验继承、部分样品继续及来源追溯。
- 集中确认减少重复输入；确认范围必须展示清楚，测量信息仍须具备实际来源。
- 部分保存支持暂停恢复，但不能绕过阶段完成或库存提交的必需信息检查。
- 实施时需修改旧术语中“模板的默认值视为实际执行”的规则，并保持新旧模板兼容。
